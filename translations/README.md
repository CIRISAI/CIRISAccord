# Accord Translations (machine-generated, draft)

Per-locale translations of the CIRIS Accord, mirroring the `accord/` file
structure under `translations/{code}/`. **These are machine translations**
(LLM, glossary-guided), generated for accessibility and flagged for native
review — they are not authoritative. The English `accord/` tree is canonical;
where a translation and the canon disagree, the canon governs.

Workflow: each locale is translated chunk-by-chunk from the canonical files,
then a review pass verifies fidelity (math, formulas, DOIs, section numbers,
defined terms, and scriptural quotes are preserved verbatim; only prose is
translated). Terminology follows the CIRIS glossaries.

Status: rolling out need-first (Tier-0 hardest-resourced languages first).
Review status per locale: `draft / needs_native_review`.
