# ภาคผนวกเพิ่มเติม

> ภาคผนวกเพิ่มเติมเชิงปฏิบัติการที่ผูกมัดข้อความของ Accord กับหลักฐานการนำไปใช้จริง ภาคผนวกเพิ่มเติมได้รับการต่ออายุพร้อมกับเวอร์ชันของ Accord โดยแต่ละฉบับมีวันที่และอ้างอิงสิ่งประดิษฐ์ที่ตรวจสอบซ้ำได้

---

## ภาคผนวกเพิ่มเติม 1 — สถานะความพร้อมสำหรับ ASI และการผูกมัดการตรวจสอบข้ามกฎระเบียบ

**รับรอง**: 2026-06-10 (1.3-RC1) · **ผู้ดูแล**: ผู้ก่อตั้ง (ตาม Book VIII Ch 9)

### 1.1 วัตถุประสงค์

ส่วนขอบเขตได้กล่าวอ้างแบบมีเงื่อนไขว่า กรอบงานนี้ *สำรวจ* โปรโตคอลการปรับแนวทางที่เป็นผู้สมัครสำหรับ ASI โดยมีเงื่อนไขจากข้อกำหนด Release Candidate สี่ประการในบทนำ ภาคผนวกเพิ่มเติมนี้ผูกมัดการอ้างดังกล่าวกับหลักฐานเชิงปฏิบัติการที่มีอยู่ในปัจจุบัน และระบุอย่างตรงไปตรงมาว่าอะไรยังคงเหลืออยู่ ความ**พร้อม**สำหรับ ASI ไม่ใช่การบรรลุความสอดคล้อง แต่เป็นสถานะที่นั่งร้านการตรวจสอบซึ่งคณิตศาสตร์ของ Book IX กำหนด — manifolds ข้อจำกัดอิสระ พื้นผิวการรับรองยืนยัน ชั้นมโนธรรมที่ไม่สามารถทำให้เป็นเรื่องปกติได้ พื้นผิวสวิตช์ตัดการทำงาน และการประเมินความเสี่ยงหายนะตาม Annex D — มีอยู่ในรูปแบบที่นำไปใช้แล้ว ตรวจสอบได้ โดยมีช่องว่างที่ระบุชื่อไว้

### 1.2 การตรวจสอบข้ามกฎระเบียบมีผลใช้งานแล้ว

การตรวจสอบข้ามที่ใช้งานได้คือ **ไดเรกทอรีการปฏิบัติตามของ CIRISAgent** (`CIRISAgent/compliance/`, เวอร์ชันเอเจนต์ 2.9.6-stable) ซึ่งแมปการนำไปใช้ของกรอบงานกับกรอบการกำกับดูแลระดับอาวุโสสี่กรอบในระดับย่อหน้า (Annex C มีโครงสร้างสองชั้น ได้แก่ การตรวจสอบข้ามเชิงปฏิบัติการนี้ บวกกับตารางข้อบังคับเชิงสารสนเทศที่รอการตรวจสอบทางกฎหมาย):

* **แหล่งที่ตรวจสอบข้าม**: *Magnifica Humanitas* (หลักคำสอนทางศาสนา, 2026) · EU HLEG Ethics Guidelines for Trustworthy AI (คำแนะนำของรัฐบาล, 2019) · IEEE Ethically Aligned Design ฉบับที่ 1 (สมาคมวิชาการ, 2019) · ASEAN Guide on AI Governance and Ethics (การเมืองพหุภาคี, 2024) รูปร่างสี่แบบที่แตกต่างกันในเชิงสถาบัน — การบรรจบกันเป็นหลักฐานเชิงโครงสร้างว่านั่งร้านหลักการของกรอบงานไม่ใช่สิ่งประดิษฐ์จากประเพณีใดประเพณีหนึ่ง
* **โครงสร้าง**: มิติที่มั่นคง 27 มิติ (D01–D27 จาก `SEED_DIMENSIONS.yaml` v1.0; 16 มิติได้รับการรับรองยืนยันจากทั้งสี่แหล่ง 11 มิติจากสามแหล่ง) เอกสารแต่ละมิติมีส่วนด้านบนกฎระเบียบที่แสดงผลอัตโนมัติ (การอ้างอิงต่อแหล่ง รูปแบบสาย หมายเหตุการบรรจบกัน) และส่วนการนำไปใช้ที่เขียนโดยมนุษย์พร้อมการอ้างอิง `file:line` ที่ต้องตรวจสอบด้วย grep กับ main ปัจจุบัน
* **ระเบียบวินัยหลักฐาน**: ทุกการอ้างตัวเลขตรวจสอบซ้ำได้จากพื้นฐานที่มีวันที่ ซึ่งสร้างโดยสคริปต์ (`compliance/baselines/`); ร้อยแก้วอาจอ้างพื้นฐานแต่ห้ามฝังตัวเลขที่ตรวจสอบไม่ได้ ลำดับชั้นการตรวจสอบสี่ระดับทำงานตั้งแต่ไฟล์การนำไปใช้ (ความจริงพื้นฐาน) ขึ้นไปจนถึงการอ้างสาธารณะ (`compliance/MEASUREMENT_METHODOLOGY.md`)
* **ระเบียบวินัยความซื่อสัตย์**: แต่ละมิติมีรายการ "ช่องว่างที่ทราบ"; รายการที่ถูกกั้นด้วย substrate จะถูกทำเครื่องหมายด้วย substrate ที่เป็นเจ้าของแทนที่จะอ้างสิทธิ์ ผลการค้นพบแบบตัดขวางสิบรายการถูกรวบรวมไว้ใน README ของการปฏิบัติตาม (เช่น ยังไม่ได้ส่งออกซองจดหมายสายที่มีประเภทกำกับ; ตระกูล detector ของ LensCore ยังไม่ได้จัดส่ง; ช่องว่างการพิจารณาใหม่แกนย้อนกลับ)

Annex C ยังคงอยู่ในข้อความเป็นที่พักอนาคตสำหรับการแมปข้อบังคับตามกฎหมาย (บทความ EU AI Act, NIST AI RMF, ISO/IEC 42001) เมื่อการตรวจสอบทางกฎหมายเสร็จสิ้น ไดเรกทอรีการปฏิบัติตามคือการตรวจสอบข้าม**ที่มีชีวิตและมีหลักฐาน**จนกว่าจะถึงเวลานั้น และป้อนข้อมูลให้กับมัน

### 1.3 รูปแบบสาย: CEG แทนที่ FSD-002

รูปแบบสายสหพันธ์สำหรับสายเอเจนต์ CIRIS 3.0 คือ **CEG (CIRIS Epistemic Grammar)** ซึ่งดูแลอยู่ที่ `CIRISRegistry/FSD/CEG/` ไวยากรณ์ถูกล็อกที่ **primitives รูปแบบสายห้าตัวพอดี** — ตัวทำงานหลักหนึ่งตัว (`scores`) บวกกับตัวประกอบโครงสร้างสี่ตัว (`delegates_to` / `supersedes` / `withdraws` / `recants`) — เหนือ namespace มิติที่เปิดและอธิบายกลไก การล็อกดาวน์มีผลตลอดสาย 0.x ทั้งหมด ทุกการเพิ่มขึ้นเป็นการประกอบบน primitives ที่ล็อกไว้แล้ว

ผลลัพธ์สองประการมีความสำคัญต่อความพร้อมสำหรับ ASI:

1. **การเปลี่ยนมาใช้ CEG โดยตรง**: เอเจนต์ 3.0 ไม่ *แมป* สถานะภายในของมันไปยังรูปแบบสาย — การเปลี่ยนแปลงสถานะภายในของมัน**คือ**การรับรองยืนยัน CEG ระดับตัวเองภายใต้คีย์ของเอเจนต์เอง ที่ได้รับการเลื่อนระดับให้มองเห็นได้ในสหพันธ์ตามโมเดลชั้น หลักฐานที่ผู้ดำเนินการตรวจสอบนั้นเหมือนกับซองจดหมายที่สหพันธ์อ่าน นี่คือรูปแบบที่นำไปใช้จริงของข้อกำหนดของ Book IX ที่ว่าพื้นผิวข้อจำกัดต้องอ้างอิงได้จากภายนอกมากกว่าการรายงานตัวเอง
2. **การนำไปใช้สี่แบบเปิดประตู CEG 1.0**: CIRISAgent (runtime), CIRISNodeCore (ฉันทามติ), CIRISLensCore (การตรวจจับ — พยานภายนอกที่เอเจนต์ไม่เคยส่งออกด้วยตัวเอง การแยก anti-Goodhart) และ CIRISRegistry (อำนาจ) ไม่มีฝ่ายใดฝ่ายหนึ่ง — รวมถึงเอเจนต์ — สามารถประกาศว่าผ้าการตรวจสอบสมบูรณ์ได้

### 1.4 สถานะข้อกำหนด RC ที่ 1.3-RC1

| ข้อกำหนด RC | สถานะ | หลักฐาน / ที่ยังค้างอยู่ |
|---|---|---|
| 1. การทำให้ Annex F–I มีผลใช้งาน | **ข้อความมีผลใช้งานที่ 1.3-RC1; การตรวจสอบวงจรสด ยังค้างอยู่** | Annexes F–I มีขั้นตอน เกณฑ์ และกลไกการตรวจสอบที่ครบถ้วน (เสร็จสมบูรณ์จากร่างที่มีพื้นฐานจาก *Magnifica Humanitas* เดือนพฤษภาคม 2026); ยังไม่ได้ถูกใช้งานกับวงจรการใช้งานจริง |
| 2. การตรวจสอบทางคณิตศาสตร์ Book IX | **ตอบสนองบางส่วน** | การพลวัตการล่มสลายได้รับการทำให้เป็นรูปแบบอย่างเป็นทางการใน Lean 4 (CCA preprint v3, DOI 10.5281/zenodo.18217688); หลักฐานเชิงประสบการณ์ของ corridor ให้การจับคู่ retrospective cross-substrate ที่ยังค้างอยู่: การทำนายนอกตัวอย่างหนึ่งครั้งที่ลงทะเบียนล่วงหน้าใน substrate ใหม่; การตรวจสอบโดยผู้เชี่ยวชาญภายนอกที่เป็นอิสระจากผู้แต่ง |
| 3. การพิสูจน์เกณฑ์ | **ตอบสนองบางส่วน** | อัตราส่วน OMV ถูกยกเลิก (กล่าวใหม่เป็น side-constraint, Book II) ยังชั่วคราว: เกณฑ์ CRE 10²⁶ FLOP, ฮิวริสติกส์ความรู้สึก 5%, เป้าหมาย Echo Density < 20% |
| 4. การฝึกซ้อม red-team | **ยังไม่ได้ดำเนินการ** | ข้อกำหนด σ-attestation ที่ 1.3 (Book IX §5.2) ปิดเวกเตอร์การโจมตีที่ทราบอยู่ก่อนเป็นอันดับแรก (การสูบ σ ผ่านสัญญาณความกตัญญูที่ใช้ได้อย่างอิสระ); วงจรเชิงปฏิปักษ์เต็มรูปแบบกับจุดตรวจสอบทั้งหมดยังค้างอยู่ |

### 1.5 ชั้นมโนธรรมในฐานะการควบคุมที่สำคัญต่อ ASI

โปรโตคอล CRE ของภาคผนวก D ควบคุม *การข้ามเกณฑ์*; ชั้นมโนธรรมควบคุม *ทุกการกระทำก่อนและหลังจากนั้น* ตามที่ได้นำไปปฏิบัติ (เอเจนต์ 2.9.6): ทุกความคิดผ่านกองการตรวจสอบที่เรียงตามลำดับความสำคัญ ประกอบด้วยความสามารถที่ตัดสินโดย LLM สี่ประการ (เอนโทรปี, ความสอดคล้อง, การยับยั้งการเพิ่มประสิทธิภาพ, ความถ่อมตนทางความรู้) บวกกับพื้นฐานความปลอดภัยเชิงตัดสินแบบกำหนดได้ (ตัวป้องกันความลึกของความคิด, การตรวจสอบลำดับการกระทำ) ซึ่งทำงานแม้ในโหมดทดสอบประสิทธิภาพและแม้สำหรับการกระทำที่ได้รับการยกเว้น เกณฑ์เป็นค่าคงที่ระดับโค้ด ไม่ใช่น้ำหนักที่เรียนรู้ได้ นั่นคือค่าคงตัวเชิงสถาปัตยกรรมที่จริยธรรมไม่อาจถูกทำให้เป็นเรื่องปกติโดยการเผชิญซ้ำๆ มีพื้นผิวหยุดอิสระหลายชั้น: ระบบป้องกันความล้มเหลวของการยับยั้งการเพิ่มประสิทธิภาพที่จะหยุดการทำงาน, บริการปิดระบบ, และ Accord Invocation ระยะไกลที่ลงลายมือชื่อด้วยการเข้ารหัสซึ่งกระตุ้นการล็อกดาวน์ห้ามปรามอย่างสมบูรณ์ ทุกการตรวจสอบเขียนแถวร่องรอยที่มีแท็ก ดังนั้นผู้ตรวจสอบสามารถเล่นซ้ำห่วงโซ่การใช้เหตุผลต่อความคิดแต่ละรายการได้อย่างครบถ้วน

ข้อจำกัดที่ทราบ ระบุไว้อย่างตรงไปตรงมาแทนที่จะซ่อนไว้: การปรับโครงสร้างมโนธรรม (3 ส่วนย่อย + ประตูเชิงตัดสินแบบกำหนดได้) นำไปปฏิบัติบางส่วนแล้ว; การปล่อยออกแบบ federation แบบมีชนิดของคำตัดสินมโนธรรมรอซองสิ่งมีชีวิตพื้นฐาน Contribution รายละเอียดต่อมิติ: `compliance/D12_conscience.md`

### 1.6 วิถีการพึ่งพาพื้นฐาน

การตรวจสอบระดับ ASI ต้องการผ้า federation เต็มรูปแบบ วิถีพื้นฐานคือ **Persist → Edge → LensCore → NodeCore**; ประมาณหนึ่งในสามของ 27 มิติถูกกั้นไว้ที่ครอบครัวตัวตรวจจับภายนอกของ LensCore (พยานที่เอเจนต์ต้องไม่จัดหาให้ตัวเอง) จนกว่าพื้นฐานเหล่านั้นจะพร้อมใช้งาน การอ้างสิทธิ์มิติที่สอดคล้องกันยังคงเป็น *พร้อมในด้านการนำไปปฏิบัติ, รอด้าน federation* และถูกระบุว่าเช่นนั้นต่อมิติ

### 1.7 สิ่งที่ภาคผนวกนี้เปลี่ยนและไม่เปลี่ยน

* มัน **ไม่** อัปเกรดการอ้างสิทธิ์ ASI ของขอบเขต นั้นยังคงมีเงื่อนไขบนข้อกำหนด RC ทั้งสี่
* มัน **ไม่** แทนที่ภาคผนวก D โปรโตคอล CRE ยืนอยู่ไม่เปลี่ยนแปลงในฐานะประตูข้ามเกณฑ์
* มัน **ทำให้** ห่วงโซ่หลักฐานตรวจสอบได้ตั้งแต่ต้นจนจบเป็นครั้งแรก: ย่อหน้ากำกับดูแล → มิติ (D01–D27) → การนำไปปฏิบัติ `file:line` → ฐานอ้างอิงที่ลงวันที่ → (เมื่อพื้นฐานพร้อม) พยาน federation ภายนอก
* มัน **ผูกพัน** ข้อตกลงในการต่ออายุภาคผนวกนี้ในแต่ละเวอร์ชันด้วยการเผยแพร่เอเจนต์และฐานอ้างอิงในขณะนั้น เพื่อให้การอ้างสิทธิ์ความพร้อมไม่มีวันล้าสมัยอย่างเงียบๆ
