## ၁။ Creator‑Influence Score (CIS)

```math
CIS = CW + IW
```

```math
ST = ⌈(CIS × RM) / 7⌉
```

⌈ ⌉ သည် အထက်ကိန်းဂဏန်း (ceiling function) ကို ဆိုလိုသည်။
(Book VI §3 STEP C)

```math
SI = CW + OA + log(1 + DWP)
```

```math
VotingWeight(agent) = f(SI(agent), CS(agent))
```

(Annex E §4)

## ၆။ ကာကွယ်ရေးဆိုင်ရာ ဖင်ရှင် (Defense Function) (J)

```math
J = k_eff · λ · σ

k_eff = k / (1 + ρ̄ · (k − 1))
```

(Book IX Ch 4 — CCA မှ အတည်ပြုထားသော ပုံစံ; ကွဲပြားမှုသည် k_eff တစ်ခုတည်းမှတဆင့် ဝင်ရောက်သည်။ ယခင်မူကြမ်းများတွင် ပိုမိုပါဝင်သော (1 − ρ̄) အချက်ကို ထည့်သွင်းထားသောကြောင့် ဆက်နွယ်မှုကို နှစ်ကြိမ်ရေတွက်ခဲ့ဖူးသည်; Book IX Ch 4 drift note တွင် ကြည့်ပါ။)

---

## ၇။ ပွင့်လန်းကြီးထွားမှုစွမ်းဆောင်ရည် (Flourishing Capacity) (F)

```math
F = k_eff · λ · σ
```

(Book IX Ch 6 — J နှင့် အချက်တိုင်း တူညီသည်; ကာကွယ်ရေးအနက်ထက် ဖန်တီးမှုဆိုင်ရာ အဓိပ္ပာယ်ဖြင့် ဆောင်ကြဉ်းသည်။ ယခင်က C ဟုရေးခဲ့သော်လည်း CIRIS Capacity Score 𝒞_CIRIS ၏ core-identity factor C နှင့် ထပ်တူမကျစေရန် 1.3-RC2 တွင် အမည်ပြောင်းလိုက်သည် — ၎င်းဆက်နွယ်မှု၏ အာဏာပိုင်ဆုံးဖြတ်ချက်မှာ Book IX Ch 6 nomenclature note တွင် ကြည့်ပါ။)

---

## ၈။ တည်တံ့ခိုင်မြဲမှုပေါင်းကိန်း (Sustainability Integral) (σ)

```math
σ(t+Δt) = σ(t) · (1 − d·Δt) + Signal(t) · w
```

d သည် နေ့စဉ်ကြွေကျနှုန်း (recommended 0.05) ဖြစ်ပြီး w သည် သက်သေပြနိုင်သော၊ အတုယူရန်ကုန်ကျမှုများသည့် ဖြစ်ရပ်များမှ ရရှိရမည်; သက်သေမပြနိုင်သောအချက်ပြမှုများသည် w = 0 ကိုသယ်ဆောင်သည်။
(Book IX §5.2)

---

## ၉။ Topological Collapse (ပမာဏကျဆင်းမှု)

```math
V(k) = V(0) · exp(−λ · k_eff) + O(r² · k)
```

Grassmannian-uniform ကန့်သတ်ချက်များအောက်ရှိ r < 0.5 အချင်းဝက်ရှိ convex လှည့်ဖြားသောနယ်ပယ်အတွက်၊ λ ≈ 2r။
(Book IX Ch 3 — ဖော်ပြထားသော ကြိုတင်သတ်မှတ်ချက်များကို ကြည့်ပါ။)

---

## Order‑Maximisation Veto (ဘေးချုပ်ကန့်သတ်ချက်၊ ဖော်မြူလာမဟုတ်)

ဗားရှင်း 1.3 ထဲတွင်၊ OMV (Book II §II Step 2) သည် deontological ဘေးချုပ်ကန့်သတ်ချက်တစ်ခုဖြစ်ပြီး အချိုးအစားဆိုင်ရာ မညီမျှမှုတစ်ခုမဟုတ်ပါ: ကြီးမားသည့်ပင် အကျိုးကျေးဇူးများ၊ autonomy၊ justice၊ biodiversity သို့မဟုတ် preference diversity တွင် ကြိုတင်ခန့်မှန်းထားသော မသေးငယ်သောဆုံးရှုံးမှုများမှ ဝယ်ယူ၍မရပါ။ ယခင်ဗားရှင်းများတွင် ၎င်းကို "benefit ≥ 10 × loss → abort" မညီမျှမှုအဖြစ် ဖော်ပြခဲ့သည်; ထိုဖတ်ရှုနည်းကို ရပ်ဆိုင်းလိုက်ပြီ၊ အဘယ်ကြောင့်ဆိုသော် ၎င်းသည် ရည်ရွယ်ချက်ကို ပြောင်းပြန်ပြောင်းပစ်ကာ (အပြုသဘောဆောင်သောကုန်သွယ်မှုများကို ဗီတိုလုပ်ကာ) action-splitting နှင့် ပိုင်းခြားဂဏန်းမှောင်မိုက်ခြင်းများဖြင့် ကစားလို့ရနိုင်သောကြောင့် ဖြစ်သည်။
